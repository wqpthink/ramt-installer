## 为什么是 RAMT

还在用 **PuTTY + WinSCP**、**Xshell + Xftp** 这样两个软件、两份配置来回切换吗？

RAMT 只专注一件事：**连上服务器，一边敲命令，一边管文件。**

- 🪟 **终端与资源同屏**：同一个 Tab 里左边 Terminal、右边资源区，比例随意拖；不用再开第二个软件。
- 🔗 **一台主机只配一次**：终端、文件浏览、上传下载共用同一条 SSH 连接，密码只输一次。服务器会话数不够时自动补一条连接，也不会再问你密码。
- 🖱️ **拖进来上传，拖出去下载**：从资源管理器拖文件进来即上传；选中远程文件直接拖到桌面即下载（系统原生拖拽，不是"另存为"对话框）。
- 🪜 **跳板机只配一次**：给目标主机设置好跳板链路（最多 5 级）后，直接点目标主机就能连上；终端、文件、传输、代理隧道全部自动经过跳板。
- 🌐 **一个端口，两种代理**：通过 SSH 访问内网时，同一个本地端口同时提供 **SOCKS5** 和 **HTTP** 代理 —— 浏览器、`curl`、`HTTPS_PROXY`、只认 HTTP 代理的老工具都能直接用。
- 🔒 **安全不靠自觉**：密码和私钥只交给系统安全存储（Windows DPAPI）加密，绝不明文落盘；服务器指纹变化时红色警告并默认拒绝连接。
- 🤖 **脚本和 AI Agent 也能用**：内置 HTTP API（REST + WebSocket，默认只监听本机，也可开放给局域网），外部程序可以直接使用 RAMT 已配置好的主机、跳板机和凭据来执行命令、操作终端、读写文件和上传下载，指纹确认和密码都通过 API 完成，不需要有人守在界面前。
- ♻️ **关了再开，一切还在**：Tab 顺序、分屏比例、文件所在目录全部恢复，并自动重新连接。
- 🧘 **没有多余的东西**：没有账号、没有云、没有广告、没有侧边栏，数据只在你的电脑里。

## 📦 下载

前往 **[Releases 页面](https://github.com/wqpthink/ramt-installer/releases/latest)** 下载最新版本。提供 Windows 10 / 11 的「安装版」和「绿色版」，按电脑的处理器选择 x64 或 ARM64：

| 处理器 | 安装版（推荐，支持一键自动更新） | 绿色版（免安装） |
|---|---|---|
| **x64**（Intel / AMD，绝大多数电脑） | `RAMT-x.y.z-win-x64-setup.exe` | `RAMT-x.y.z-win-x64-portable.exe`（单个文件，数据保存在同目录 `ramt-data/`，可放 U 盘随身带） |
| **ARM64**（Windows on ARM，如骁龙笔记本） | `RAMT-x.y.z-win-arm64-setup.exe` | `RAMT-x.y.z-win-arm64-portable.exe` |

> **首次运行提示**（当前安装包尚未进行代码签名）：若出现「Windows 已保护你的电脑」，点击 **更多信息 → 仍要运行**。公司电脑的杀毒软件可能会拦截，请联系 IT 放行。

## 🚀 三步上手

1. **新增连接**：点击顶部的连接按钮（或按 `Ctrl+T`），在面板工具栏点「新增连接」，填写主机、用户名，选择密码或私钥认证。
2. **打开**：双击连接即可打开终端；右键可选择「打开 Terminal」或「打开资源」。
3. **分屏**：在 Tab 里按 `Ctrl+Shift+F` 显示资源视图、`Ctrl+Shift+T` 显示终端视图 —— 两者同时打开就是左右分屏。

首次连接某台服务器时会显示它的主机指纹，确认后即被记住。

## ✨ 功能一览

### 连接管理
- 多级分组，拖拽排序与移动；模糊搜索，连接再多也能秒找。
- 密码 / 私钥认证，私钥支持 **OpenSSH、PEM、PPK（PuTTY）** 格式和带口令的私钥；也支持服务器的键盘交互式认证。
- 密码可以不保存，连接时再询问。
- **跳板机（ProxyJump）**：连接方式选「通过跳板机连接」，从已有连接中按顺序选择跳板机（最多 5 级，可调整顺序、直接新建或编辑跳板机）。每一级使用各自的认证信息和主机指纹；多台目标主机可共用同一台跳板机；连接失败时会指出是哪一台出了问题。仍被使用的跳板机不能删除。
- 导入 / 导出连接配置，换电脑一键迁移（含分组结构）。

### 终端
- 多 Tab，Tab 太多时自动收进右侧下拉列表。
- 单独缩放当前终端字号（`Ctrl +` / `Ctrl -` / `Ctrl+滚轮`），不影响其他 Tab。
- 终端内搜索、链接可点击、完整 Unicode 与中文宽字符支持。
- 大量输出（如 `tail -f`、编译日志）不卡界面：内置背压控制，持续输出逐行实时到达。
- 默认使用系统文字渲染，字形与 IDE 一致；可在设置中切换 GPU 加速。
- 可设置字体、字号、光标样式、回滚行数、浅色 / 深色 / 跟随系统主题。

### 资源区（SFTP 文件管理）
- 浏览、新建、重命名、删除、复制 / 剪切 / 粘贴、显示隐藏文件、复制路径。
- 文本与图片快速预览。
- 「在此目录打开终端」；把文件拖到终端即插入其路径。
- 上传文件或整个文件夹，下载到指定目录或直接拖到桌面。
- 传输面板：进度、取消、重试；大文件流式分块传输，不占内存；下载先写临时文件，完成后才改名，不会留下半截文件。
- 同名冲突时可选择覆盖 / 跳过 / 保留两者。

### SSH 隧道（动态端口转发，等同 `ssh -D`）
在 **设置 → 代理隧道** 中添加：选择经由哪个连接、监听地址和端口。只要该连接有打开的会话，隧道就自动生效：

```bash
# SOCKS5（域名由远端解析）
curl --proxy socks5h://127.0.0.1:1080 http://intranet.example/
# HTTP 代理 —— 同一个端口
export HTTPS_PROXY=http://127.0.0.1:1080        # Linux / macOS
$env:HTTPS_PROXY = 'http://127.0.0.1:1080'      # Windows PowerShell
```

浏览器、数据库客户端、Proxifier、Clash 等工具同样可以指向这个端口。

### 服务器资源监控
在 **设置 → 扩展功能** 中打开「服务器资源监控」，窗口右下角会实时显示当前 Tab 所连服务器的 **CPU / GPU、内存、磁盘** 使用情况（每 2 秒刷新，占用高时变色提醒）。面板半透明、不挡操作，切换 Tab 自动跟随，关闭开关即停止采集。支持 Linux 服务器（GPU 需安装 NVIDIA 驱动的 `nvidia-smi`），只读取系统信息，不会在服务器上留下任何文件。

### 本地 API（脚本 / 自动化 / AI Agent）
在 **设置 → 本地 API** 中查看访问地址、复制访问令牌（默认开启，只监听本机 `127.0.0.1:18765`）。外部程序通过 HTTP 直接使用 RAMT 里已配置好的主机、跳板机和凭据：

```bash
TOKEN=...   # 设置 → 本地 API → 复制令牌
curl -H "Authorization: Bearer $TOKEN" http://127.0.0.1:18765/api/v1/hosts
```

- 能力：主机管理、建立会话、执行命令（输出、退出码、超时、取消）、交互式终端（WebSocket）、文件浏览与读写、后台上传下载与进度事件。
- 与界面完全隔离：API 使用自己的连接和任务，不会占用或打断界面的会话，也不会在界面弹出任何询问 —— 首次连接时的主机指纹确认、没有保存的密码，都通过 API 请求本身提供。
- 可在设置中关闭 API、修改端口，或开放到局域网（`0.0.0.0`），修改立即生效。

完整的接口与错误码可以带上令牌读取 OpenAPI 3.1 描述：`http://127.0.0.1:18765/api/v1/openapi.json`。

### 注册
- 未注册时可以保存 **1 个连接配置**（跳板机也算一个）；打开连接后的终端、资源区、上传下载、代理隧道、服务器资源监控、本地 API 等功能全部可用。
- **申请注册码**：请添加腾讯微信号 **`starsealun`** 进行申请，申请时附上本机的机器码（见下一条）。
- 注册码与电脑绑定：在 **设置 → 注册** 复制本机的**机器码**发给作者，收到为这台电脑签发的注册码后粘贴进去，连接配置数量不限。注册码离线校验、不联网，设置页显示授权对象和到期日期（30 天内到期时醒目提示）。
- 注册码到期或移除后恢复为未注册：已有的连接配置全部保留、照常使用，只是不能再新增。

### 其他
- 中文 / English 界面。
- 外观主题：深色、浅色、**柔光极光**（暖雾白为底、薄荷绿为品牌色的轻盈配色，终端同步换成深石墨的 Lumi Flow），也可以跟随系统。
- 启动时自动检查 GitHub 上的新版本；安装版一键「重启并安装」。

## 🔐 数据与安全

| 项目 | 说明 |
|---|---|
| 数据位置 | 安装版：系统用户数据目录（如 `%APPDATA%\RAMT`）；绿色版：程序旁的 `ramt-data/` |
| 密码 / 私钥 | 由操作系统安全存储加密，只能在本机、当前用户下解密 |
| 主机指纹 | 首次连接需确认；变化时红色警告并默认拒绝；导入文件中的指纹一律忽略 |
| 网络 | 除检查更新访问 GitHub 外，不连接任何第三方服务，没有统计与遥测 |
| 本地 API | 默认只监听本机 `127.0.0.1`，每个请求都需要访问令牌（加密保存，可随时重新生成，旧令牌立即失效）；拒绝来自网页的请求。开放到局域网（`0.0.0.0`）时通信未加密，只应在可信网络中使用；不需要时可在设置中关闭 |
| 注册码 | 保存在本机数据库中，每次使用时离线校验签名与到期日期；不随连接配置导出，导入备份也不会覆盖 |
| ⚠️ 导出文件 | 为方便迁移，**导出的 JSON 文件包含明文密码与私钥**，请像对待密码本一样妥善保管 |

## 🤔 RAMT 适合你吗？

**适合：**
- 每天 SSH 到服务器，经常需要上传配置、下载日志。
- 服务器只能用密码或动态口令登录，不想反复输入。
- 需要借一台 SSH 主机访问内网网页、数据库或接口。
- 服务器只能经过一台或多台跳板机才能访问。
- 想让脚本或 AI Agent 通过本机 API 调用 SSH、SFTP、终端和文件传输。
- 想要一个打开就能用、界面干净的工具。

**暂时不适合**（这些功能目前没有，如果是刚需，推荐 [Tabby](https://github.com/Eugeny/tabby)、[electerm](https://github.com/electerm/electerm)、[WindTerm](https://github.com/kingToolbox/WindTerm)）：
- 本地与远程端口转发（`-L` / `-R`）、X11 转发、Agent 转发
- Telnet、串口、RDP、VNC 等其他协议，或用作本地终端
- 多设备配置同步、`rz` / `sz`、多终端同步输入、AI 助手

## ❓ 常见问题

**换电脑后打不开保存的密码？**
密码由系统安全存储绑定在原电脑和用户上，直接拷贝数据目录无法解密。请在旧电脑上「导出连接配置」，到新电脑「导入」。

**绿色版和安装版的数据能互通吗？**
不能自动互通，二者数据目录不同。可以用导出 / 导入迁移。

**关掉软件时传输还没完成？**
未完成的任务下次启动会显示为「已中断」，不会自动续传，需要手动重新发起。

**隧道端口启动失败？**
多半是端口被占用，换一个端口后点「重试」。另外服务器需允许 TCP 转发（OpenSSH 默认允许，`AllowTcpForwarding yes`）。

**本地 API 提示端口已被占用？**
通常是另一个 RAMT 正在运行（例如同时打开了安装版和绿色版）。在 **设置 → 本地 API** 换一个端口即可；不使用 API 也可以直接关闭。

**提示「需要注册」，不能再新增连接？**
未注册时只能保存 1 个连接配置（跳板机也计入）。在 **设置 → 注册** 粘贴注册码即可不限数量；注册码到期后同样会恢复这个限制，已有连接不受影响。

**换了电脑或重装了系统，注册码不能用了？**
注册码只能在签发时对应的那台电脑上使用，重装系统或换电脑后机器码会变化。把新的机器码（设置 → 注册）发给作者，重新获取注册码即可。

**注册码提示「已停用」或「已作废」？**
作者更换了签名密钥或作废了该授权编号，旧注册码不再有效。请联系作者获取新的注册码，输入后即可恢复。

**拖到桌面时提示"已准备好，请再次拖出"？**
较大的文件需要先下载到本地临时目录，下载完成后再拖一次即可。超过 64MB 的文件建议用右键「下载到…」。

## 📄 许可协议

RAMT 是闭源软件，只发布安装包。可以免费使用（最多保存 1 个连接配置），在 **设置 → 注册** 输入注册码后不限数量。安装和使用即表示同意 **用户许可协议**：安装时会显示全文，安装后可在 **设置 → 关于** 中随时查看（文件为安装目录 `resources` 文件夹中的 `LICENSE.txt`）；软件中使用的开源组件及其许可证见同一文件夹中的 `THIRD_PARTY_NOTICES.txt`。
